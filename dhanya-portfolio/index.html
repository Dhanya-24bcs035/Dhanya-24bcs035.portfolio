01

AI Resume Matcher

A pure Java web app that scores resumes against a job description using TF-IDF and cosine similarity.

It reads PDF and TXT resumes, finds skill gaps, classifies seniority, compares skills side by side and generates technical interview questions. It runs on Java’s built-in HTTP server with zero external dependencies.
